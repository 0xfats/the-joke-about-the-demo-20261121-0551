# The joke about the demo

[![make.fun · the-joke-about-the-demo-20261121-0551](https://make.fun/badge/the-joke-about-the-demo-20261121-0551.svg)](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551?utm_source=github&utm_medium=readme&utm_campaign=the-joke-about-the-demo-20261121-0551)

One one-line joke about working beside AI coding agents, written to
`/output/entry.txt` by a small deterministic Python program.

The joke: an AI coding agent rehearses a demo forty times flawlessly,
then crashes on the one run with humans in the room — and files a bug
report against the audience.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that
variable is set, for local testing). The output is a fixed string:
no network, no randomness, no model call, so every run produces the
same file byte for byte.
